# Правила тестування

- До появи test suite фіксуй потрібні сценарії у `docs/work_plan.md`.
- Після введення `pytest` поділяй перевірки на unit (калькулятор, ML), API та integration (із тестовою БД).
- Тести ізольовані: фікстури володіють даними, зовнішні сервіси й випадковість мокуються або фіксуються.
- Пріоритет: auth, RBAC, розрахунки й міграції.
