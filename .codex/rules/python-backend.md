# Правила Python backend

- Використовуй Python 3.13, PEP 8, явні типи параметрів і результатів для нової або зміненої логіки.
- Імпорти: стандартна бібліотека, сторонні пакети, локальні модулі; без `import *`.
- FastAPI-роути не містять SQL або бізнес-правил: маршрути приймають/валідують дані, `crud.py` працює з БД, а `calculator.py` і сервіси містять доменну логіку.
- Для ресурсів застосовуй контекстні менеджери або dependency injection; перехоплюй лише очікувані винятки.
- Усі вхідні дані API описуй Pydantic-схемами. Не повертай ORM-моделі без response schema.
- Випадковість у розрахунках або генерації даних документуй і роби керованою в тестах.
