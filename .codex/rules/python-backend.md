# Локальні правила: Python і FastAPI

## Стиль і типи

- Використовуй Python 3.13, PEP 8, явні типи параметрів і результатів для нової або зміненої логіки.
- Імпорти розміщуй у порядку: стандартна бібліотека, сторонні пакети, локальні модулі. Не використовуй `import *`.
- Не використовуй mutable значення за замовчуванням; `None` перевіряй через `is None`.

## FastAPI та доменна логіка

- Маршрути не містять SQL або правил IDC: маршрути валідовують HTTP-введення, `crud.py` працює з БД, а `calculator.py` і сервіси містять доменну логіку.
- Усі вхідні дані API описуй Pydantic-схемами. Не повертай ORM-моделі без явного `response_model`.
- Для сесій застосовуй dependency injection; перехоплюй лише очікувані винятки й не приховуй першопричину помилки.
- Випадковість у розрахунках або генерації даних документуй і роби керованою в тестах.
