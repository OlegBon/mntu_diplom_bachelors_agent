# Локальні правила: перевірка змін

## Мінімальний набір

Виконуй лише релевантні перевірки та фіксуй команду й результат у `docs/progress.md`:

```powershell
.\.venv\Scripts\python.exe -c "from backend.main import app; print(app.title)"
cmd /c "cd frontend && npm run build"
git diff --check
```

## За типом зміни

- Для API додай smoke-перевірку запущеного сервера; для auth або CORS перевір конкретний browser/API-сценарій.
- Для БД погодь окрему безпечну перевірку локальної MariaDB. Не запускай seed без дозволу.
- Для frontend перевір відрендерену сторінку й відповідний користувацький сценарій.
- Не заявляй про успішну перевірку, якщо команда не запускалася або завершилась помилкою.
