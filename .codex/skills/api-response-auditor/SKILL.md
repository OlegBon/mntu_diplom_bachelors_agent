# API Response Auditor

Перевіряй контракти й HTTP-відповіді FastAPI Diamant ID через `scripts/audit-api.mjs`. Скрипт призначений тільки для локального API й не виконує жодного запиту, що змінює дані.

# Умови активації

Активуй, якщо користувач просить: «зроби аудит ендпойнтів», «перевір відповіді API», «сформуй звіт щодо API».

# Інструкції з виконання

Дій суворо за кроками й не запускай руйнівний seed або запити, що змінюють дані, без явного дозволу користувача.

## Крок 1: Підготовка

- Переконайся, що локальний FastAPI вже запущений. Скрипт сам сервер не запускає.
- За замовчуванням ціль — `http://127.0.0.1:8000`. Інший локальний порт передай лише як `API_AUDIT_BASE_URL=http://127.0.0.1:<порт>`.
- Не передавай віддалений URL: скрипт приймає лише `localhost` або `127.0.0.1` через HTTP.

## Крок 2: Запуск

Виконай з кореня репозиторію:

```powershell
cmd /c "cd frontend && npm run audit:api"
```

Скрипт перевіряє корінь API, OpenAPI, публічні читальні маршрути, 404 неіснуючого звіту, 401 межі захищених GET-маршрутів і локальний CORS preflight. Він не виконує login, POST, PUT, DELETE, seed і не використовує токени.

## Крок 3: Результат

Прочитай `docs/audits/api-audit-latest.md` і, якщо аудит успішний, звір кількість перевірок із консольним підсумком. Timestamped-звіти та latest-звіт є локальними артефактами й ігноруються Git.

# Формат відповіді

Зроби короткий виклад перевірених маршрутів, проблем і меж аудиту. Не заявляй про повний аудит без фактичних перевірок.
