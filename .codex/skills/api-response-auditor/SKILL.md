# Мета навички

Проведення аудиту API за допомогою заздалегідь підготовленого скрипта проєкту для надійних і відтворюваних перевірок.

# Умови активації

Активуй, якщо користувач просить: «зроби аудит ендпойнтів», «перевір відповіді API», «сформуй звіт щодо API».

# Інструкції з виконання

Тобі ЗАБОРОНЕНО писати власні скрипти або напряму використовувати `fetch` для цього завдання. Дій суворо за кроками:

## Крок 1: Запуск аудиту

За допомогою інструмента виконання команд у терміналі запусти скрипт аудиту:

- локально: `npm run audit:api`;
- для публічного cloud MVP: `API_AUDIT_BASE_URL=https://convertly-hub.bon.kharkov.ua npm run audit:api`.

`API_AUDIT_BASE_URL` містить лише public origin застосунку. Не додавай до нього URL
Supabase, Gotenberg, MinIO або жодні credentials: у віддаленому режимі вони приватні,
а їхній стан перевіряється агреговано через `GET /api/health`.

## Крок 2: Очікування

Дочекайся завершення роботи скрипта у терміналі (має з'явитися повідомлення про успішне збереження).

## Крок 3: Читання звіту

За допомогою інструмента читання файлів відкрий згенерований файл `docs/audits/api-audit-latest.md`.

# Формат відповіді

1. Зроби короткий виклад прочитаного звіту `api-audit-latest.md` (статус ендпойнтів і 2–3 основні проблеми, якщо вони є).
2. Заверши відповідь суворо фразою: _"Аудит API завершено. Звіти сформовано. Чекаю на подальші вказівки."_
