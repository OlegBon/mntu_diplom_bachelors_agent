# API Response Auditor

Перевіряй контракти й HTTP-відповіді FastAPI Diamant ID. Автоматизованого скрипта аудиту в репозиторії поки немає, тому не вигадуй команду `npm run audit:api`.

# Умови активації

Активуй, якщо користувач просить: «зроби аудит ендпойнтів», «перевір відповіді API», «сформуй звіт щодо API».

# Інструкції з виконання

Дій суворо за кроками й не запускай руйнівний seed або запити, що змінюють дані, без явного дозволу користувача.

## Крок 1: Межі аудиту

- Прочитай `backend/main.py`, відповідні Pydantic-схеми й frontend-виклик, якщо він є.
- Зафіксуй середовище, базовий URL та маршрути, що перевіряються. Не розкривай значення `.env`.

## Крок 2: Безпечні перевірки

- Перевір статуси, заголовки, `response_model`, обробку 401/403/404/422 та CORS для фактично запущеного frontend origin.
- Для GET-маршрутів використовуй лише безпечні читальні сценарії. Для захищених маршрутів не розкривай токенів і не записуй їх у звіт.
- Познач, які маршрути не перевірялися та чому.

## Крок 3: Результат

Подай таблицю: маршрут, очікуваний контракт, фактичний статус, результат і ризик. За потреби збережи звіт у `docs/audits/`, але не створюй файли зі штучними результатами.

# Формат відповіді

Зроби короткий виклад перевірених маршрутів, проблем і неперевірених припущень. Не заявляй про повний аудит без фактичних перевірок.
