# Web Performance

Застосовуй на запит performance-аудиту або перед deployment. Не вигадуй Core Web Vitals: відокремлюй виміряні дані від припущень.

Перевіряй frontend-збірку й реальний браузерний сценарій, обсяг статичних ресурсів, API-час, SQLAlchemy-запити та індекси. Для майбутнього тестового домену окремо оцінюй CORS, TLS, стиснення статики, CDN/кешування та мережеву відстань між FastAPI і PostgreSQL.

У звіті подай таблицю: рівень (клієнт, мережа, сервер, БД), факт або ризик, вплив, критичність; після неї — пріоритетні дії. Не запускай інфраструктуру й не змінюй код без окремого запиту.
