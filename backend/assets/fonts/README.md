# Fonts used in public-passport PDFs

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` are redistributed DejaVu Sans
fonts. They are included as application assets so Ukrainian PDF text does not
depend on the fonts installed on the server. DejaVu Sans is distributed under
the Bitstream Vera license with public-domain DejaVu additions; see the
[upstream project](https://dejavu-fonts.github.io/).
