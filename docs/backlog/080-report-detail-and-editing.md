# Приватний перегляд і редагування звіту

## Мета

Дати експерту та admin повний захищений перегляд звіту, контрольоване
редагування та переходи життєвого циклу.

## Scope

- Повна приватна сторінка: параметри, обчислення, докази, історія й
  комерційний стан.
- Owner/admin RBAC для перегляду та редагування.
- Контрольовані дії review, issue і void із аудитом автора й часу.
- Обмеження редагування критичних даних після `issued`.

## Критерії готовності

- Немає доступу до чужого приватного звіту поза дозволеним RBAC.
- 404/403/валідація й дозволені переходи покриті критичними API-перевірками.
