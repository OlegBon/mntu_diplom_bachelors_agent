# Основа версіонованих міграцій

## Мета

Ввести Alembic для MariaDB до розширення схеми звітів. Це не міграція на
PostgreSQL, а контрольований спосіб змінювати локальну схему без `create_all`.

## Scope

- Налаштувати Alembic для поточного SQLAlchemy-шару й явної конфігурації БД.
- Створити стартову ревізію фактичної схеми без руйнування даних.
- Описати команду upgrade, downgrade, backup-передумови та перевірку ревізії.
- Підготувати правила для наступних schema/backfill-міграцій.

## Не входить

- Перенесення MariaDB → PostgreSQL.
- Автоматичний запуск руйнівного `scripts/seed_db.py`.

## Критерії готовності

- Нова порожня локальна БД відтворюється через міграції та контрольований seed.
- Поточна БД може бути перевірена на актуальну ревізію без втрати даних.
- Є протестований rollback для безпечної тестової ревізії.
