# Майстер створення звіту

## Мета

Створити послідовний майстер, що дозволяє експерту сформувати та зберегти
чернетку звіту без підміни експертних висновків автоматичними розрахунками.

## Scope

- Рівно три responsive-кроки: ідентифікація/4C, геометрія/IDC, висновок/медіа.
- Окреме редаговане поле фактичної дати дослідження / оцінки; дата створення не є його заміною.
- Preview наступного номера не резервує ID; остаточний номер призначає `POST /reports`.
- Довідники форми та grade mappings завантажуються з API/БД, не hardcode з frontend.
- Нова чернетка має `market_status=not_for_sale`; комерційний стан переноситься до 080 detail/edit.

- Кроки: ідентифікація, параметри каменю, експертні спостереження,
  комерційні дані, медіа, перевірка й збереження.
- Створення і повторне редагування `draft`.
- Live IDC-розрахунок як preview; backend — єдине джерело істини під час save.
- Явне маркування введених, розрахованих та експертно підтверджених даних.
- Підключення `media_assets` після завершення задачі `050`.

## Критерії готовності

- Чернетка не стає виданим звітом випадково.
- Помилки валідації зрозумілі поруч із відповідними полями.
- Є критичні нові API, JS/DOM і E2E-перевірки без зміни наявних тестів без
  окремого погодження.
