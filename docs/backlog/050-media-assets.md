# Медіа звітів

## Мета

Додати безпечне завантаження і використання фото, plotting-діаграм та
доказових матеріалів звіту.

## Scope

- Окрема сутність `media_assets` із типом, storage key, MIME, розміром,
  контрольним хешем, автором, датою та видимістю.
- Локальне gitignored-сховище на кшталт `storage/reports/<report-id>/`;
  файли не зберігаються у `frontend/dist` і не комітяться.
- Типи: `stone_photo`, `plotting_diagram`, `instrument_image`,
  `supporting_document`.
- Перевірки типу, розміру, авторизації, належності звіту й безпечна видача.
- Приватність за замовчуванням; окремий дозвіл на матеріал у публічному
  паспорті.

## Критерії готовності

- Файл фізично зберігається, метадані записуються в БД, а не в один рядок
  моделі звіту.
- Власник/admin має контрольований доступ; гість не може вгадати приватний URL.
- Є критичні API та browser-перевірки завантаження/відображення.
