# Версіоновані довідники та правила оцінювання

## Мета

Дозволити admin актуалізувати довідники без зміни змісту вже створених звітів,
публічних паспортів або PDF.

## Проблема

Поточні звіти зберігають коди, а UI читає текст із актуальних
`reference_values` і `grade_mappings`. Просте редагування підпису або правила
змінить відображення історичних даних заднім числом. Це неприйнятно для
виданого звіту та переданого паспорта.

## Scope

- Версіонований каталог із effective date, обов’язковою причиною зміни та
  необов’язковим джерельним документом/посиланням.
- Новий report прив’язується до чинної версії; попередні reports і їхні
  browser-паспорти/PDF використовують історично закріплену версію.
- Окрема версія IDC-правила для значень, що впливають на Proportions/Final Cut.
- Admin draft/review/publish workflow, append-only audit trail, RBAC та
  API/frontend regression-тести.

## Не входить

- Автоматичний backfill або перекласифікація historical reports.
- Авторитетні ціни й FX з 110.
- Публічні media з 130.

## Критерії готовності

- Зміна має причину, автора, момент чинності й за потреби документ-джерело.
- Зміна діє на нові reports, але не змінює інтерпретацію historical reports,
  public passports чи вже згенерованого PDF.
- API не дозволяє переписати published version або обійти RBAC.
