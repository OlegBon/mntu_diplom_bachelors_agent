# Dashboard звітів

## Мета

Перетворити dashboard із демо-розмітки на робочий список звітів.

## Scope

- Дані лише через актуальний API-клієнт, без демо-рядків і дубльованих
  довідників у frontend.
- Пошук, фільтри за станом звіту й ринковим станом, allow-list сортувань,
  пагінація.
- Видимість даних за роллю та авторством.
- Зрозумілі loading, empty, error і forbidden-стани.

## Критерії готовності

- Dashboard показує фактичні дані API і зберігає фільтри в межах сценарію.
- Є важливі API/DOM перевірки та один цільовий E2E-flow.
