# RBAC: admin не створює звіти

## Мета

Закріпити на сервері погоджене правило: admin адмініструє звіти, експертів,
довідники й аналітику, але не створює первинні експертні звіти.

## Поточний стан

Frontend не показує admin пункт «Новий звіт». Однак поточний
`POST /diamonds/` приймає будь-якого авторизованого користувача, тому UI не є
захистом правила.

## Scope

- Дозволити створення звіту лише ролі gemologist на сервері.
- Повернути для admin зрозумілий `403` без створення запису.
- Додати або розширити API-тести для gemologist/admin create-report.
- Звірити меню з фактичними серверними правами після зміни.

## Критерії готовності

- Admin не може створити звіт ані через UI, ані прямим API-запитом.
- Gemologist зберігає чинний сценарій створення.
- Тести перевіряють обидві ролі.
