# UX і візуальна основа продукту

## Мета

До реалізації основних екранів оновити навігацію, дизайн-систему й адаптивну
оболонку Diamant ID у професійному SaaS-стилі зі сапфірово-синім акцентом.

## Scope

- Оновити `DESIGN.md`, токени та базові компоненти у стилі чистого
  інформаційного інтерфейсу, близькому за дисципліною до Convertly Hub.
- Спроєктувати меню для гостя, gemologist і admin.
- Визначити loading, empty, error, success і forbidden-стани.
- Підготувати responsive layouts ключових екранів.
- Використати Build Web Apps для реалізації та browser-перевірок.
- Використовувати згенеровані зображення лише там, де вони допомагають:
  landing, onboarding, empty states або перевірка паспорта.

## Рішення

- Основний акцент — сапфірово-синій (`#2563EB`), не фіолетовий акцент
  Convertly Hub.
- Для таблиць, форм, sidebar і критичних дій лишаються текстові підписи й
  стандартні іконки; декоративні зображення їх не замінюють.

## Критерії готовності

- Є затверджена інформаційна архітектура для трьох ролей.
- Нові базові компоненти та токени не суперечать доступності й `DESIGN.md`.
- Зібраний frontend і перевірені ключові adaptive UI-стани.
