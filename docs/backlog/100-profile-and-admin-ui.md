# Профіль і адміністративний інтерфейс

## Мета

Завершити робочий контур користувача та адміністратора без передчасної
реалізації ML-аналітики.

## Scope

- Профіль поточного користувача та безпечна зміна доступних йому даних.
- Admin UI для експертів, ролей, довідників і ринкових даних.
- Виділити місце для майбутньої аналітики без показу демо-ML як фактів.

## Критерії готовності

- Небезпечні admin-дії доступні тільки admin і мають зрозумілий UI-стан.
- Довідники редагуються через API, а frontend не зберігає їх дублікати.
