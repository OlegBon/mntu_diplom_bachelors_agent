# Профіль і адміністративний інтерфейс

## Мета

Завершити робочий контур користувача та адміністратора без передчасної
реалізації ML-аналітики.

## Scope

- Профіль поточного користувача та безпечна зміна доступних йому даних.
- Admin UI для експертів, ролей і довідників; інтерфейс ринкових даних
  залежить від [110](./110-authoritative-market-data-and-fx.md).
- Виділити місце для майбутньої аналітики без показу демо-ML як фактів.
- Перед підключенням будь-якого UI перевірити та виправити контракт
  `/statistics/expert-performance`: під час read-only audit 16.09.2026 він
  повернув `500` на локальній відновленій MariaDB. Не вважати його надійним
  джерелом UI-даних до окремого API/integration regression-тесту.

## Критерії готовності

- Небезпечні admin-дії доступні тільки admin і мають зрозумілий UI-стан.
- Довідники редагуються через API, а frontend не зберігає їх дублікати.
